# 键帽试衣间

上传自己键盘的照片和一套键帽的官方键位图，生成「你的键盘换上这套键帽」的真实效果图。适合在团购或购买前判断配色、字符和配列是否合适。

- 基于你的真实照片修改：拍摄角度、光线、外壳、配列、艺术帽都保留，只换键帽。
- 支持只装了轴体或定位板的套件照片。
- 没有照片也可以直接选 Dock77 的六种配色（浅灰、深灰、银色、冰蓝、冰粉、蓝紫）来试。
- 可额外上传最多 4 张 add-on kit 图（如 Mac 修饰键、novelties），对应的键会优先使用。
- 上传的图片不保存；生成结果只在内存里保留 1 小时。

## 工作原理

1. 视觉模型先逐颗读出键盘上的每个键，并在键位图里找到对应键帽的颜色和字符。
2. 同时，视觉模型在键位图上找出约 30 颗代表性的键帽（修饰键、导航键、方向键和几颗字母、数字、F 键），程序把它们剪下来、打乱顺序拼成一张样张。图像模型只看样张、不看整张键位图，就不会照搬键位图的排法（例如漏画 Enter 右边的 Insert、Delete）。找不到足够的键时退回使用整张键位图。
3. 图像模型根据清单和样张修改原照片，输出与原照片比例大致一致的 PNG。程序向图像模型请求长边 2048 px，但模型实际返回的图更小：16:9 的照片实测长边约 1680 px（1672–1683 px）。

一次生成大约需要一到两分钟，需要 OpenAI API Key。

## 本地运行

需要 Node.js 24 或更高版本。

```bash
npm ci
export OPENAI_API_KEY=sk-...
npm run build
npm start          # 打开 http://localhost:3000
```

运行测试：`npm test`

## 用 Docker Compose 部署

1. 在项目目录新建 `.env` 文件：

   ```
   OPENAI_API_KEY=sk-...
   # 可选：使用其他兼容 OpenAI 的接口地址
   # OPENAI_BASE_URL=https://...
   # 可选：识图（第 1 步）单独走另一个兼容 OpenAI 的接口（如 CPA），生图仍用上面的 OPENAI_*
   # VISION_BASE_URL=https://.../v1
   # VISION_API_KEY=...
   # 可选：访问密码。设置后打开网页要先输入密码，输对后浏览器记住 30 天；改密码后所有人需重新输入
   # ACCESS_PASSWORD=...
   ```

2. 启动：

   ```bash
   docker compose up -d --build
   ```

   服务监听 **31430** 端口。更新代码后重新执行同一命令即可。

注意：生成任务保存在内存中，只能运行一个容器；重启会丢失进行中和已生成的结果。
